# Fresh Juice

Ежедневный журнал JUICE о рынке видеоконтента: Scripted, Non-scripted, Branded content, Event & Sport, Doc, Digital.

Сайт статический: `index.html` читает `data/index.json` (список выпусков) и `data/<issue_id>.json` (выпуск и его новости). Картинки лежат в `img/`. Выпуски собирает и публикует Claude по расписанию.
