# Fresh Juice

Ежедневный журнал JUICE о рынке видеоконтента. Сайт: https://sobinoviv-cloud.github.io/fresh-juice/

- `index.html` — страница журнала (последний выпуск + архив «Все выпуски»).
- `data/index.json` — список выпусков и настройки; `data/<issue_id>.json` — выпуск.
- `img/<story_id>.webp`, `img/<story_id>-s.webp` — картинки новостей.
- `<дата>/` (например `2026-10-28/`) — постоянная ссылка на выпуск с превью для Telegram; `og/<issue_id>.jpg` — картинка превью.
- `tools/make_og.js` — генерирует превью и страницу выпуска: `node tools/make_og.js <issue_id>`.

Оценки и статистика включены 4 ноября 2026:

- `feedback.js` / `feedback.css` — анонимные оценки 1–5 внутри новости. Один изменяемый голос на новость в браузере.
- Считаются посещения выпуска, уникальные браузеры, видимые заголовки, открытия новостей и 15 секунд активного чтения. Предзагруженные слайды не являются просмотрами; повторная загрузка в том же визите не увеличивает счётчики.
- Данные хранятся на собственном JUICE HUB в отдельном сервисе. Публичного отчёта нет; редактор получает агрегаты через защищённый серверный доступ. Имена, Telegram-профили и отпечатки устройств не собираются.
- Среднюю оценку нужно читать вместе с числом голосов. Другой браузер/устройство считается отдельным посетителем; сайт общедоступен, поэтому статистика не доказывает принадлежность посетителя к компании.
